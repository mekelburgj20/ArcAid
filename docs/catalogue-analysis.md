## 8. CSV Output Summary

Master CSV written to `docs/catalogue-master.csv`:
- Unique `global_games` rows: **4,188**
- Total CSV rows (one per source claim): **5,132**

Columns:
- `global_game_id` — stable ID; group here to see all source claims for one record
- `source` — opdb | vps | igdb | wizard | manual
- `source_id` — that source's external ID
- `source_count` — how many sources contributed to this global_games row (1-3)
- `is_frankenstein` / `frankenstein_reasons` — flagged records from cross-type merge
- `name`, `type`, `subtype`, `year`, `manufacturer` — current (post-merge) values
- `platforms`, `features`, `themes` — semicolon-joined arrays
- `ipdb_url`, `external_url`, `imported_from` — source references
- `opdb_id`, `vps_id`, `igdb_id` — all three IDs present on the shared row, for cross-reference

**Important limitation:** The CSV shows the _current_ name after merge. If IGDB
and VPS both had entries named "Alice in Wonderland", the CSV reflects whichever
won the merge — the original source-specific titles are lost in the DB. To recover
them, we'd need to re-fetch from sources (not done in this script).

   distinct games that should not share a row.
2. **Review the "Name Collisions" section** — see what the dedup algorithm must
   distinguish. Pay attention to cases where multiple _pinball_ machines share a
   name (e.g. 1950s EM vs. 1990s SS of the same title).
3. **Agree on dedup rules.** Proposed:
   - Never merge across `type` boundaries.
   - Within pinball, only merge when there's an explicit cross-reference
     (VPS `ipdbUrl` ↔ OPDB IPDB number, or VPS has `opdbId`).
   - Normalized-name matches alone are never sufficient to merge — flag for review.
   - Require manufacturer+year agreement as a secondary confirmation.
4. **Un-merge existing Frankensteins.** For the ~464 cross-type merges, split off
   the IGDB claim into its own row with `type=video_game`, clear `igdb_id` and
   video-game subtype/platforms from the pinball row, restore the IGDB title via
   targeted re-fetch.
5. **Replace `GlobalGameService.upsert()`** with rules above and re-run imports.
